Bucketed Name Generation

Names are generated using demographic buckets to reflect U.S. population diversity. First name selects a bucket by weight, then 75% of the time the last name comes from the same bucket, 25% from a different bucket (reflecting intermarriage, adoption, cultural blending). First names include gender presentation metadata (male female neutral) for avatar matching.

Regional Location Generation

Addresses are generated using regional buckets for realistic city/state pairing. 80% of the time city and state come from the same region, 20% cross-region (reflecting real U.S. mobility). ~30% of addresses include unit/apartment numbers.

AI-Generated Avatars

Avatars are organized by gender presentation (male/female/neutral) and appearance range (light/medium/dark). Each identity is assigned a gender from their first name and an appearance range independently. The avatar bucket is then {gender}_{appearance} (e.g., "female_light", "male_dark").
